📖 The 4 Golden Rules of Unix Paths

Whenever you feel lost in the terminal, picture yourself standing inside a room in a building:

Symbol Name Meaning Example
pwd Print Working Directory Turns on the GPS: tells you which room your feet are standing in right now. pwd → /Users/ali/campus
. Single Dot "This room right here" (current folder). cp ../data/a.txt . (copy into here)
.. Double Dot "One level UP" (the parent folder above me). Chain with /: ../.. = two levels up. cd ../library (up one, then into library)
~ Tilde "My Home Folder" (e.g. /Users/ali). Works from anywhere! cd ~/agu_campus/library
/ Slash At the very beginning: the Root of the whole computer. In the middle: separates folder names. cd /Users/ali/agu_campus

⚡ Relative Path vs. Absolute Path

  • Relative Path (does NOT start with / or ~): Directions starting from where your feet are standing right now. Example: cd ../library or cat notes/diary.txt.
  • Absolute Path (always starts with / or ~): The full postal address from the top. Works no matter where you are standing! Example: cd ~/agu_campus/library.
